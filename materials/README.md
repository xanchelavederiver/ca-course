# Course materials (LaTeX sources)

```
materials/
├── sem1/ sem2/
│   ├── lectures/NN-slug/    notes.tex (wrapper) + notes-body.tex (ca-notes), slides.tex (ca-slides),
│   │                        examples.yaml -> examples/*.tex (taskgen worked examples)
│   ├── seminars/NN-slug/    handout.tex (ca-handout); the classroom sheet is sheets/semN/seminar-NN-slug.yaml
│   └── exam/                questions-body.tex + questions.tex / questions-refs.tex (ca-exam)
└── capstone/NN-topic/       spec.tex (ca-capstone); reference implementation later (Plan 4)
```

Lectures and seminars, their numbers, slugs and titles come from `course.yaml`
at the repo root (see the README, «Course content»). `taskgen course scaffold`
creates a missing `NN-slug/` from the `00-template/` directories, which are
also built by `make demos`.

Build any document: `make pdf FILE=materials/sem1/lectures/02-big-integer-arithmetic/notes.tex`
→ `build/materials/sem1/lectures/02-big-integer-arithmetic/notes.pdf`; everything:
`make materials`; the semester books: `make book SEM=1`.

Shared styles are in `latex/` (found automatically via `TEXINPUTS`/`BIBINPUTS`):

| file | for | notes |
|---|---|---|
| `ca-notes` | lecture notes | `\begin{lecture}{N}{title}...\end{lecture}` in `notes-body.tex`; class option `book` (semester book: lectures are chapters); theorem envs; `\checkyourself{}` + `\checkyourselfsection` (collected per lecture, with page refs); `furtherreading` env with `\readitem[locator]{key}{comment}` (prints the bibliography in standalone notes); `\taskexample{name}` |
| `ca-slides` | lecture slides | beamer 16:9 + `ca` theme; `\titleframe`, `canvasframe[opts]{title}`, `theoremframe[env]{title}` (statement + proof area), `\proofarea[h]`, `\notearea[h]`, `\penspace[h]`, `\aside{question}` |
| `ca-handout` | seminar handouts | `\seminar{N}{title}`, `\makehandouttitle`, `reminder` box |
| `ca-sheet` | task sheets | option `solutions`; `\solution{}`; used by taskgen templates |
| `ca-exam` | exam questions | option `refs`; `\examtitle`, `\topic`, `\question{text}{refs}`, `literature` env |
| `ca-capstone` | capstone specs | `\capstonetitle`, `\goal`, `\functionality`, `\requirements`, `\details`, `\schedule`, `\references` |
| `ca-figures.sty` | notes + slides | `\xgcdtable{a}{b}`, `\euclidchain{a}{b}` (computed by TeX), `\rhoshape{tail}{cycle}`, `\ecaddfigure`, `\ecdoublefigure`, `\latticefigure{v1}{v2}`, `\personicon{color}{name}` |
| `ca-biblio.sty` + `ca-refs.bib` | notes (exams, capstones) | biblatex/biber, GOST numeric style; `@online` entries with `keywords = {online}` are listed separately |

All classes load `ca-common.sty` (pdfLaTeX, T2A/utf8, Russian babel, math macros such as
`\ZZ`, `\Zn{n}`, `\Znx{n}`, `\GF{q}`, `\Mod{m}`, `\congr{a}{b}{m}`, `\ord`, `\legendre`;
algpseudocode with Russian keywords for `\begin{algorithm}...\begin{algorithmic}`).

Conventions for lecture notes:

- labels are prefixed with the lecture number (`\label{l3:bezout}`) and must be unique within
  the semester (the book); `taskgen course check` reports duplicates;
- no `\newcommand` in `notes-body.tex` (two lectures defining the same macro break the
  book) — use `\providecommand` with a lecture-specific name;
- references to other lectures are plain text («см. лекцию~3»);
- numeric examples are either generated by taskgen (`examples.yaml`) or verified with Sage.
